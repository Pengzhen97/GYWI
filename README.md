# Research Idea Generation with RAG + GraphRAG

This project implements a scientific idea generation system using **Retrieval-Augmented Generation (RAG)** combined with **GraphRAG**.  
It retrieves semantically relevant literature chunks and related papers from an author collaboration graph, then leverages a Large Language Model (LLM) to generate novel and feasible research ideas.

## 📂 Project Structure
```
project_root/
├─ data_rag/                 # Contains vector DB and graph data
│  ├─ vector_db_semantic/
│  │  ├─ faiss.index
│  │  └─ metadata.json
│  ├─ author_paper_graph_final_b.json
│  └─ updated_mcq_with_id_abstract.json
├─ openl/                    # GraphRAG root directory (with prompts, settings, etc.)
├─ src/
│  ├─ config.py               # Configuration file (paths, API keys, default parameters)
│  ├─ prompts.py              # Prompt templates for LLM
│  ├─ utils/                  # Utility functions
│  ├─ vectorstore/            # FAISS vector store wrapper
│  ├─ graph/                  # Graph query module
│  ├─ graphrag/               # GraphRAG client wrapper
│  ├─ llm/                    # LLM client wrapper
│  └─ pipeline/
│     └─ idea_generator.py    # Main pipeline for generating research ideas
├─ output/                    # Generated results
├─ main.py                    # Entry point (run with specified paper ID)
├─ requirements.txt
└─ README.md
```

## 🚀 How to Run

### 1. Install dependencies
It is recommended to use a virtual environment:
```bash
pip install -r requirements.txt
```

### 2. Prepare your data
Ensure the following files are available:
- `data_rag/vector_db_semantic/faiss.index`
- `data_rag/vector_db_semantic/metadata.json`
- `data_rag/author_paper_graph_final_b.json`
- `data_rag/updated_mcq_with_id_abstract.json`

> **Note:** Avoid placing the project in a folder with non-ASCII (e.g., Chinese) characters in the path, as FAISS on Windows may fail to read the index file.

### 3. Set your API key
Edit `src/config.py`:
```python
API_KEY = "your-deepseek-api-key"
BASE_URL = "https://api.deepseek.com"
```

### 4. Run the pipeline
Edit `main.py` to set the `PAPER_ID` and parameters, then run:
```bash
python main.py
```

## 📄 Output Files
By default, results are saved to the `output/` directory:
- `{paper_id}_detail.txt` → Full intermediate results (GraphRAG + RAG chunks)
- `{paper_id}_result.txt` → Final research idea generated by the LLM

## 🛠️ Key Components
- **FAISS Vector Store** → Retrieves semantically similar chunks from papers.
- **Graph Query** → Fetches N-hop related papers from the co-author graph.
- **GraphRAG Client** → Queries GraphRAG for conceptual adjacency summaries.
- **LLM Client** → Sends prompts to the DeepSeek API to generate ideas.

## ⚠️ Notes
- Ensure FAISS index files are in a path without Chinese characters if running on Windows.
- The system currently supports DeepSeek as the LLM, but can be adapted for other OpenAI-compatible APIs.
